# Perfil público da organização i-9.ai

Este repositório especial versiona a apresentação pública da organização
[I-9-AI](https://github.com/i-9-ai) no GitHub.

- `profile/README.md`: conteúdo exibido na página da organização;
- `profile/assets/`: ativos visuais usados pelo perfil e evidência da troca do
  avatar.

Mudanças devem passar por branch e Pull Request. O merge e alterações externas
na identidade da organização continuam sujeitos à aprovação do owner.
